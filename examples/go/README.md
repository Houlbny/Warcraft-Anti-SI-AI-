# go 库存练习

这是可独立运行的原创离线示例，不需要模型或网络。需要本机已经安装对应工具链。

运行：

```text
go run main.go
```

初始标准输出：`remaining=12`。这是有意保留的业务错误，销售应减少库存。

1. 探索：计算函数是 `remaining`。
2. 预测：初始代码输出 `remaining=12`。
3. 修复：在 BUG 标记行将加法改为减法。标准输出应为 `remaining=8`。
4. 扩展：在修复后将负库存限制为 0，并将示例订单改为 12。标准输出应为 `remaining=0`。

每步均以退出码 0 为运行要求。源码只是声明级静态索引示例，不代表完整语义分析。
