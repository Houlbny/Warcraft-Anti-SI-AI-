# 使用与排查指南

## 安装与启动

准备 Python 3.11+、Node.js 22+（含 npm）；Git 导入另需本机 Git。系统工具由用户自行安装。安装脚本只准备项目依赖、虚拟环境和前端构建，不会安装 JDK 等系统工具。

以下命令在项目根目录执行：

| 操作 | Windows PowerShell | macOS |
| --- | --- | --- |
| 安装项目依赖 | `.\setup.ps1` | `sh setup.sh` |
| 前台启动 | `.\start.cmd` | `sh start.sh` |
| 后台启动或重启 | `.\restart.cmd` | `sh restart.sh` |
| 停止 | `.\stop.cmd` | `sh stop.sh` |
| 指定端口重启 | `.\restart.cmd --port 8766` | `sh restart.sh --port 8766` |

服务仅监听本机回环地址。首次从 `8765` 起选择空闲端口，以后沿用保存值；以终端打印的地址为准。前台运行按 `Ctrl+C` 停止，后台日志位于数据目录的 `server.log`。

停止与重启脚本先核对本项目受管理实例身份，再请求正常退出，不按端口或 PID 强杀其他程序。正在分析、准备任务、评审或运行时会拒绝关闭，请等待操作结束。未运行时停止脚本直接提示。默认等待 30 秒，可用 `--timeout 60` 调整（1–120 秒）。旧启动器没有登记实例时，先在原终端按 `Ctrl+C`，再使用新脚本。

更新源代码后重新执行安装脚本，或在 `frontend` 中运行 `npm run build` 后重启。只修改 Python 服务代码时重启即可。macOS 尚需实际环境验证。

## 配置模型

打开“模型设置”，填写 OpenAI 兼容的 Chat Completions 根地址（通常以 `/v1` 结尾）、服务商支持的模型名和密钥，保存后点击“测试已保存的设置”。远程接口要求 HTTPS；本机回环服务可不填密钥。界面密钥留空会保留已保存值。

密钥使用系统凭据管理器；Windows 可回退到当前用户的 DPAPI 加密存储，macOS 使用 Keychain。存储不可用时明确报错，不静默改为明文或会话存储。应用不自动复用环境变量中的接口密钥。

生成超时可设置为 30–900 秒，默认 300 秒，是单次模型响应读取等待限制，并非整个冒险的总期限。连接测试使用较短请求，测试成功后仍可能发生格式不兼容、上下文过大或生成超时。

分析、规划、任务生成和评审会发送所选材料片段；评审还可能发送回答、代码改动和真实运行输出。导入过滤明显凭据、隐藏文件与常见依赖目录，但不能保证识别所有敏感内容，发送前请检查材料。

## 导入、范围与职业

选择文件、文件夹、本机绝对路径或 Git 地址，再点击“导入材料”。Git 只接受不含凭据的 HTTPS 或 `git@host:owner/repo` 地址，需要已具备访问权限；应用不提供托管平台登录或交互认证。

导入后先查看解析提示，勾选要分析的文件，按需填写 PDF 起止页并保存范围。范围更改会清除之前的分析结果；已分配给冒险的材料不能修改范围，需重新导入。填写可选关注重点后，明确点击“分析材料”。AI 返回材料摘要、类型和 1–3 个职业建议；随后使用已有角色或创建该职业的角色。当前角色不适配时会提示原因，并提供推荐角色入口，原角色进度保留。

导入时可在“文字编码”中选择 `utf-8-sig`（兼容 BOM，默认）、`utf-8`、`utf-16` 或 `gb18030`；遇到编码提示时改选正确编码后重新导入。PDF 不使用此文字编码参数。

单次最多 512 个文件、20 MB；普通文字单文件最多 2 MB，PDF 最多 8 MB、500 页，提取文字总量最多 300 万字符。链接、隐藏目录、常见构建产物、二进制和明显凭据文件会被过滤；请以导入结果为准。PDF 使用 `pypdf` 文字提取，不支持 OCR；没有文字的扫描页不会纳入学习范围。

“分析范围”显示选定文字量和自动分批数量。点击分析后，程序逐批读取全部选中的可读原文，再汇总整体结构与职业建议。每批最多 24,000 字符且包含来源位置的 UTF-8 JSON 不超过 16,000 字节，超过部分会进入后续批次。批次越多，相应的模型调用和耗时也会增加。

进度区分原文读取与汇总。中断或失败时可点击“继续分析”，已成功的批次保留；材料范围、模型配置、关注重点或分析提示词变化后会重新分析，避免混用不同输入。刷新页面不会自动请求模型。全部选中原文和汇总成功后才提供职业入口；分析完成不代表所有知识点都已出题或玩家已经掌握。

## 探索与作答

进入冒险后按主题选择任务。推荐任务是建议入口，可以改选其他已开放任务；锁定目标会显示必要前置。规划不固定六个目标，首次尝试准备最多两个开放任务，成功任务逐个可用。

讲解首次默认隐藏，选择“先学习理解”查看讲解，或选择“先尝试回忆”后直接作答，需要时再查看讲解。阅读公开通过标准，查看原始材料引用，按需获取提示；已用提示会保留显示。提交后逐项查看 AI 评审。评审失败或暂不可用时回答仍保存，可修改重试或暂时探索其他任务。

单任务准备失败点击“重试”。已发布任务可“生成替代任务”，旧回答和练习副本仍保存在本地；替代任务不能降低同一目标的公开标准或执行要求。刷新与重启不自动重试 AI 操作。

在任务的“我的自评”中选择“还需复习／已经理解／能尝试运用”，填写最多 2,000 字笔记并保存。未作答时也能保存自评；自评不会使目标通过。“回忆日志”展示回答、评审反馈、提示次数及已保存自评。

主题达到必要目标后形成营地纪事，全部必要目标完成后出现阶段结语；重复提交不会重复结算。营地角色显示阶段称号与完成冒险数。

## 代码练习与执行

代码任务才显示练习文件与运行工具。打开文件后编辑文字区，点击“保存到练习副本”，选择任务指定入口并运行。运行结果显示真实状态、退出码、耗时、标准输出与错误输出。提交评审前须有实际改动，并成功运行当前版本；运行后再改动需重新运行。实际执行成功不等于满足全部学习目标，之后仍需 AI 按公开标准评审。

每个任务有独立副本，同任务连续操作保留修改，其他任务不自动继承。原始导入文件不会被编辑操作改写。**练习副本不是操作系统沙箱**，程序拥有当前用户权限；只执行可信代码，依赖、构建和代码可能访问副本以外的位置及网络。

| 学习对象 | 本地执行工具 |
| --- | --- |
| Java | JDK（`javac`、`java`） |
| Python | Python |
| JavaScript | Node.js |
| TypeScript | Node.js 与可发现的 TypeScript 编译器 |
| Go | Go 工具链 |
| Bash / POSIX sh | 对应解释器 |

Windows 不会用 cmd 或 PowerShell 冒充 Bash/sh。复杂工程、外部服务、原生依赖、自定义构建和交互输入可能需要手动准备；任意可读语言不等于任意语言可运行。缺少工具或不支持的入口会返回真实错误。应用不自动进行系统安装、全局环境修改或旧版自动构建修复。

## 开场、存档与删除

三幕开场支持暂停、上一幕、下一幕、跳过和顶部“重播开场”。方向键切换，空格暂停，Escape 跳过，Tab 切换按钮。系统设置减少动态效果时默认手动翻幕；页面隐藏时暂停计时。

默认存档在 `.warcraft/`，`CODEWARDEN_DATA` 可指定其他目录。回答和编辑草稿还会按冒险及任务保存在当前浏览器。材料、模型设置和凭据均应视为私人数据。

删除材料、冒险或角色前核对名称并确认。被冒险使用的材料不能直接删除；删除冒险会删除相应练习与进度，删除角色会删除它的所有冒险。正在处理的记录会拒绝删除。原始磁盘文件、其他角色和模型设置保留。

本次升级启动时删除受管理的旧版知识库、关卡、草稿、学习与运行历史及旧副本，不保留旧版兼容界面；原始文件、模型设置和凭据保留。要继续旧材料，重新导入。

## 常见问题

- 页面提示前端未构建：执行安装脚本或在 `frontend` 中运行 `npm run build`。
- 无可读取文字：查看编码、容量和 PDF 提示，选择较小范围或提供文字版材料。
- 分析或准备失败：检查设置与具体错误，再继续分析或重试准备。相同输入下成功的原文批次会复用；单任务失败不影响其他已发布任务。
- 提交显示待评审：回答已保存，检查接口后重新提交；不会自动视为答错或通过。
- 模型请求超出 32,000 字节：材料分析会自动分批，汇总也会按预算分组。任务规划会要求拆小过大的目标；过长的回答、代码改动或运行输出仍需精简，应用不会发送截断的评审证据。
- 运行后仍不能提交：确认有实际修改，运行的是任务要求入口，且成功记录对应当前练习版本。

开发检查命令见[首页](../README.md#开发检查)。自动测试、真实模型教学质量和 Windows/macOS 实际运行分别验证。
