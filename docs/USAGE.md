# 使用与排查指南

返回 [项目首页](../README.md)。以下命令均在项目根目录执行，前端构建命令除外。

一个独立运行的本地代码学习应用：导入源码，选择职业，由 AI 根据源码预生成章节，再按顺序阅读、解释、修改练习副本和运行验收。界面使用 React、Phaser 和 Monaco，后台为 Python/FastAPI。本地网页与 Python 服务一起运行，不需要 Docker，也不依赖 Codex 才能使用。

故事从“第十三次钟声”开始：奥术中枢接管了城市，人们逐渐失去独立维护法阵的能力。你从灰烬营地出发，与一位职业导师同行，接手一处仍在运转却尚不熟悉的据点。法师伊蕾娜带你重学语言，圣骑士加雷恩追查结构与实现，德鲁伊瑟芙关注联系和扩展。

右上角“故事”可阅读序章和人物背景。现有章节直接载入，关卡对白随顺序推进，通关后接续行程。剧情为本地展示，不要求重新生成章节，也不会改变实际学习任务、作答与验收；营地的“中枢残片”是 AI 顾问的故事身份。

目标平台为 Windows 和 macOS。当前开发与实际运行验证在 Windows 完成；macOS 尚未实测。真实模型的连通性、整章生成与关卡游玩已有实际使用验证；不同服务商与模型的结果仍以实际请求为准，本地模拟接口结果不代替服务商实际结果。

## 安装与启动

先自行安装并确认已有 **Python 3.11+、Node.js 22+（含 npm）**。安装脚本会创建项目虚拟环境、安装项目依赖并构建前端，需要能访问对应软件包源；不会替你安装 Python、Node、JDK 等系统工具。

Windows 在项目根目录的 PowerShell 中执行：

```powershell
.\setup.ps1
.\start.cmd
```

macOS 在项目根目录执行：

```sh
sh setup.sh
sh start.sh
```

首次启动从 `8765` 开始选择空闲的本机端口，以后沿用保存的端口。将终端打印的 `http://127.0.0.1:端口` 地址复制到浏览器。在启动终端按 `Ctrl+C` 停止服务。服务只监听本机回环地址。

Windows 可双击 `restart.cmd`，或在 PowerShell 执行 `.\restart.cmd`；macOS 执行 `sh restart.sh`。重启脚本沿用上次端口，在后台启动服务；服务尚未启动时也可直接使用。需指定其他端口时，执行 `.\restart.cmd --port 8766` 或 `sh restart.sh --port 8766`。后台日志保存在数据目录的 `server.log`。

停止服务：Windows 双击 `stop.cmd` 或执行 `.\stop.cmd`，macOS 执行 `sh stop.sh`。脚本等待本项目服务正常退出，不再启动新实例；存档、已保存密钥和上次端口保留。有任务进行时会拒绝停止；未运行时直接提示，无需重复处理。停止后可用启动或重启脚本继续使用。默认等待 30 秒，可通过 `--timeout 60` 调整（1–120 秒）。

脚本验证本项目实例身份后才请求关闭，不按端口或 PID 强杀程序。存在生成、运行、修复等任务时会拒绝重启，等待任务结束再执行即可；重复启动和同时重启也会被阻止。旧版启动器未登记实例，首次升级需先在原启动终端按 `Ctrl+C`，再使用新版脚本。

每次更新源代码后，需要重新构建前端；安装脚本也会完成这一步。仅修改 Python 服务代码时，重启服务即可。

## 选择职业并生成章节

主流程为：**导入项目 → 选择职业 → AI 预生成整章 → 顺序闯关**。示例按钮仅导入对应语言的示例源码，之后同样需要选角和真实模型生成；它不会提供一套无需模型即可进入的新章节，也不会用预编写任务替代失败的 AI 请求。示例中保留了用于练习的代码问题，不代表应用已自动诊断用户项目存在同类缺陷。

| 职业 | 章节侧重点 |
| --- | --- |
| 法师 | 语言知识、源码阅读和较充分的引导 |
| 圣骑士 | 项目结构、实现原理和核心功能 |
| 德鲁伊 | 全局理解、功能扩展和改动之间的联系 |

确认职业后，应用分段请求所配置的模型：**分批分析源码 → 规划统一路线 → 逐关生成 → 整章检查**。完整章节包含 **6–10 个关卡**；每关包含源码位置、明确目标、**2–4 个操作步骤**和验收方式，职业会影响生成内容。每段通过检查后立即保存草稿，整章通过后才开放游戏。模型未配置完整时，先进入设置，保存并测试后返回选角继续生成。

等待时，像素角色会随真实阶段阅读源码、绘制路线、整理关卡和检查章节，已保存的关卡逐个显示。可暂停装饰动画、翻阅本地小提示；系统减少动态效果设置也会生效。计数来自后台实际保存结果，动画不会伪造完成进度。

一次只开放第一个未完成关卡，后续关卡保持锁定。完成验收后查看结果，再点击“下一关”继续；已完成关卡可回看。角色、已生成章节、任务进度与练习修改会保存到本机，重启应用后可续玩。生成中断或失败后，点击继续按钮恢复未完成阶段，兼容的已保存分段不会重复请求；刷新或重启不会自动调用模型。源码版本、职业或模型变化时会检查缓存是否适用，受影响的内容需要重新生成。已有可玩章节不会因再次打开项目而自动重新请求模型；更换已发布章节的职业需要另建练习副本。

验收方式按关卡区分：短答案题核对已保存答案；解释题提交文字，由 AI 按源码依据和评审标准给出反馈。代码题需要实际运行指定入口；可自动匹配输出的题目要求退出码为 0 且输出符合目标，需要 AI 差异审阅的题目还要求实际改动和当前版本运行成功，再提交审阅。**AI 评审与真实运行结果分别展示**，运行成功不自动等同于通过 AI 审阅，AI 判断也不能代替实际运行。

生成章节需要模型。已经保存的关卡、步骤、提示和资料可离线阅读；具备本地工具及依赖时，答案核对与部分本地运行验收也可离线完成。解释题和 AI 差异审阅仍需可用的模型接口；依赖尚未就绪的工程运行可能还需要访问软件包源。输出匹配只验证该任务的案例，不能证明所有输入或完整业务正确。

覆盖的 7 种学习对象是 **Java、Python、JavaScript、TypeScript、Go、Bash、POSIX sh**。内部归为 6 个语言适配组：JavaScript 和 TypeScript 分别提供示例，Bash 与 POSIX sh 共用兼容的 Shell 示例。六组源码与运行说明位于 [examples](../examples/)。

| 示例组 | 运行所需的本机工具 |
| --- | --- |
| Java | JDK，包含 `javac` 和 `java` |
| Python | Python |
| JavaScript | Node.js |
| TypeScript | Node.js、可发现的 TypeScript 编译器；前端安装也会提供项目内的编译器 |
| Go | Go 工具链 |
| Shell | 脚本要求的 Bash 或 POSIX sh；Windows 不会用 cmd/PowerShell 冒充解释器 |

缺少工具时会返回具体错误，不会伪造执行成功。Windows 上仅有 WSL 启动器不代表已具备可直接使用的 Shell 运行环境。PowerShell、zsh 不属于当前被学习脚本的适配范围；产品自身可以使用 PowerShell 安装脚本。

随应用提供 **42 张中文离线知识卡**，每个适配组 7 张，包含原创代码、预期输出、误区、版本范围、来源链接和整理日期。支持语言与关键词检索和收藏；卡片正文不需要联网，访问官方来源链接需要网络。

## 在关卡中作答

“源码解释题”和“源码问答题”的答题框位于源码下方，进入工作台即可填写。左侧是阅读指引，底部固定的“去作答”会定位输入框；点击下一步阅读指引不会提交答案或完成关卡。

填写后点击“提交答案”：解释题由 AI 按本关标准逐项评审，问答题由本地服务校验，通过后解锁下一关。请求失败或回答未通过时，工作台保留已填写内容，可根据输入框下方的反馈修改后重试。文字题不要求运行源码；需要自行尝试时，可展开“运行工具”。代码修改题仍按本关要求进行真实运行或运行后的 AI 差异评审。

## 删除练习档案

在“档案”中点击对应记录的“删除”，核对名称后选择“确认删除”。这会删除该档案的练习副本、章节与关卡进度、运行和评审记录，并清理本浏览器中属于它的草稿及草稿备份。已确认并完成的删除无法撤销；原始源码、其他档案、模型接口和密钥设置保留。

删除当前档案后会返回档案列表，可重新导入测试。正在生成、运行、保存、刷新或修复的项目会拒绝删除，等待操作结束后再试。若文件清理暂时失败，界面会区分“删除未完成”和“档案已删除、部分文件待清理”；后者在下次启动时继续清理。删除过程中异常退出时，启动会依据恢复记录处理未完成操作。

## 导入自己的项目

支持导入本地目录、单文件和 Git 地址。Git 导入需要本机 Git 与已就绪的访问权限；应用不提供托管平台登录界面，也不自动安装 Git。

应用将可接受的文本源码复制到独立练习区。编辑、编译和应用自动修复针对副本，**应用不会直接改写导入时的原项目**。依赖目录、生成文件、链接和明显的凭据文件会被过滤，因此副本不保证包含原目录的全部文件；真实工程可能仍需要自行准备依赖与入口。刷新会检测原来源是否变化，并保留练习中的修改；源版本变化后可重新导入生成新章节。

Python 使用 AST 提取声明；其他语言使用屏蔽注释和字符串后的保守声明匹配。索引提供源码位置和有限结构信息，不能视为完整语义调用图，也不能据此确认跨文件或跨语言调用关系。

应用支持部分常见单文件和工程运行入口，实际命令以执行结果为准。复杂构建、特殊目录布局、外部服务、交互输入、原生依赖和自定义测试流程可能需要手动适配，不能保证任意项目开箱即跑。

## 配置模型

在应用的设置中自行填写 **OpenAI 兼容的 `base_url` 和模型名**；远程服务还需填写 API Key，本机回环模型服务允许不填密钥。保存后点击连接测试。当前采用 Chat Completions 协议；不同服务商对协议的实现可能有差异，是否可用以实际测试为准。本项目不复用已有环境变量密钥。连接测试成功仅说明短请求可用，不保证整章生成成功。

每段章节响应等待上限默认 **300 秒**，可在设置中调整为 30–900 秒。它限制单次请求连续等待响应数据的时间，不是整个生成过程的倒计时。页面显示实际等待时间与阶段；超时会区分连接与响应等待，并保留手动继续。浏览器断连后先查询后台状态，避免重复生成。分段增加了请求数量，总耗时不保证更短；超时请求仍可能已被服务商处理，重试当前段可能再次计费。

某段返回无效 JSON、字段缺失、类型错误或超出长度限制时，会显示具体字段与原因，并携带这些反馈**自动纠正重试一次**，即该段最多请求两次。仍失败则保留进度；点击继续时只重做未通过的段，并带上此前反馈。已保存且兼容的分析和关卡不重复请求。网络、鉴权、超时及源码变化不自动重试；整章内容存在实际冲突时仍需明确继续。提示词提供标准 JSON 示例与较短摘要目标，但模型一次成功不能保证。

接口地址通常填写服务商提供的 API 根地址，例如 `https://服务地址/v1`。远程接口要求 HTTPS，本机模型服务可用回环 HTTP 地址。不要把密钥放在 URL 中。

密钥优先交给系统凭据管理器保存。Windows 凭据管理器无法写入时，使用当前 Windows 用户的 DPAPI 加密后保存在数据目录的 `credentials/`；macOS 使用系统钥匙串。保存成功后重启无需重新输入；保存或读取失败会明确显示错误，不会静默退回内存。请通过正常用户终端或双击脚本启动；受限运行环境可能无法访问系统凭据或用户加密配置。

应用不会把 API Key 明文写入 SQLite 设置或普通配置文件。公开设置只返回是否配置密钥和存储状态，不回传密钥；留空保存保留已有密钥，点击“移除密钥”删除。更换服务地址时不会自动沿用原地址的凭据。旧版本仅保存在进程内存的密钥，升级后需要重新保存一次；加密文件不保证能跨用户、跨电脑或迁移数据目录后直接使用。

生成章节、提交解释或代码差异评审、请求构建诊断时，会将选取的源码片段、回答、改动、配置或日志发送到用户设置的模型接口。应用过滤常见凭据并限制上下文，但模式脱敏无法保证识别任意秘密；请先检查准备导入的项目。本地资料检索和已保存章节的阅读不会调用模型；示例源码生成章节也会调用模型。

## 执行与自动修复边界

**本地执行不是安全沙箱，只应运行自己信任的代码。** 应用有目录路径校验、已知危险操作检查、超时和停止进程等规则，并对部分缓存和产物做本地重定向。这些是应用层规则，不是操作系统隔离；源码、构建脚本和依赖仍可能拥有当前用户的文件与网络权限，也可能访问练习目录以外的位置。不能把“在副本运行”理解为对子进程副作用的完整约束。

自动修复用于实际运行失败后的环境或构建诊断，最多尝试 3 轮。最终可自动应用的范围限制为代码校验允许的**声明式配置**，例如 `tsconfig.json` 的 `compilerOptions`、`package.json` 的依赖版本；具体文件与字段白名单以当前实现为准。它不代表允许模型修改任意构建文件。

Gradle 等可执行构建配置、脚本钩子、业务源码与答案、跳过测试的改动、系统安装和全局环境修改，不属于自动应用范围：应用会拒绝自动更改或只给出诊断，需用户自行审查处理。应用不会因为模型返回了命令就执行它。配置修复会显示改动和重新运行结果，可撤销；若用户已在修复后继续编辑，撤销会报告冲突以保护工作。

业务练习使用分级提示与关卡声明的验收方式。章节只依据本次提供给模型的源码上下文生成，不能承诺完整覆盖大型工程、所有模块或全部执行路径；应结合章节覆盖说明和实际源码检查。复杂需求可能需要 AI 评审或人工判断，不能仅凭任意入口运行成功自动判为完成。单入口标准输出比较和 AI 差异审阅都不能替代完整测试套件、隐藏测试或人工代码审查。

## 数据与开发检查

默认数据目录为项目根目录的 `.warcraft/`，存放 SQLite 存档、项目记录、练习副本、凭据引用或加密文件，以及服务管理记录和日志。可通过启动服务前设置 `CODEWARDEN_DATA` 改变数据位置；启动和重启需使用相同数据目录。不要把该目录当作公开发布内容。

安装项目依赖后，在项目根目录运行后台检查：

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
```

macOS 对应命令为：

```sh
.venv/bin/python -m pytest tests -q
```

前端检查在 `frontend` 目录执行 `npm run build`。真实模型连通性需要在应用设置中另行测试；模拟接口测试只验证请求与错误处理逻辑。模块与接口约定见 [API-CONTRACT.md](API-CONTRACT.md)，角色章节与评审接口见 [CAMPAIGN-CONTRACT.md](CAMPAIGN-CONTRACT.md)。
